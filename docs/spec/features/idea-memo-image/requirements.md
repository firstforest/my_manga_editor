## 概要

作品の「何でも書ける場所」(アイデアメモ) に、資料写真・ラフ・参考画像などを
テキストと並べて置けるようにする。プロットを考えるときに文字だけでは残しにくい
イメージを、作品と一緒に手元に置いておくための機能。

ページのメモ・セリフ・ト書きは対象外 (ClipStudio Paint への書き出しはテキストだけを扱うため)。

---

## ユーザーストーリー

### US-1: アイデアメモに画像を貼りたい (priority: P1)

As a 漫画を描く人,
I want アイデアメモに画像を置きたい,
so that 参考資料やラフを作品のメモと一緒に見返せる.

#### Acceptance Criteria

- AC-1.1: WHEN 利用者がアイデアメモのツールバーで「画像を追加」を押して画像ファイルを選ぶ THE SYSTEM SHALL その画像をカーソル位置に挿入する
- AC-1.2: WHEN アイデアメモにフォーカスがある状態でクリップボードの画像を貼り付ける THE SYSTEM SHALL その画像をカーソル位置に挿入する
- AC-1.3: WHILE 画像を保存している THE SYSTEM SHALL メモ欄の上に進捗バーを表示する
- AC-1.4: WHEN 画像入りのアイデアメモを別の端末・再読み込み後に開く THE SYSTEM SHALL 同じ位置に画像を表示する
- AC-1.5: THE SYSTEM SHALL 画像を高さ 320 論理ピクセル以内に縮めて、縦横比を保って表示する
- AC-1.6: WHEN 画像を含む作品のカードを作品一覧に表示する THE SYSTEM SHALL メモのプレビューに画像の代わりの記号を出さない

#### Edge Cases

- 10 MB を超える画像 → 保存せず「画像が大きすぎます。10 MB までの画像を貼れます」と伝える
- PNG・JPEG・GIF・WebP 以外 → 保存せず「PNG・JPEG・GIF・WebP の画像を貼れます」と伝える
- オフライン・保存失敗 → 挿入せず「画像を保存できませんでした。通信状態を確かめてもう一度お試しください」と伝える
- 画像が読み込めない (削除済みなど) → その位置に「画像を読み込めませんでした」と表示し、メモの他の部分は使える

### US-2: 作品を消したら画像も片付けてほしい (priority: P2)

As a 漫画を描く人,
I want 作品を削除したときに貼った画像も消えてほしい,
so that 使わない画像がどこかに残り続けない.

#### Acceptance Criteria

- AC-2.1: WHEN 作品を削除する THE SYSTEM SHALL その作品のメモに貼った画像をすべて削除する
- AC-2.2: IF 画像の削除に失敗する THEN THE SYSTEM SHALL 作品の削除は完了させる

### US-3: 新しい版で書いたメモでも古い版が落ちない (priority: P2)

#### Acceptance Criteria

- AC-3.1: WHEN このバージョンが知らない種類の埋め込みを含むメモを開く THE SYSTEM SHALL エディタを落とさず、その位置に「このバージョンでは表示できない内容です」と表示する

---

## 対象外

- ページのメモ・セリフ・ト書きへの画像
- 画像のサイズ変更・トリミング・キャプション
- メモから消した画像の Storage 上のファイルの削除 (作品を消したときにまとめて消える)
- ドラッグ＆ドロップでの追加
