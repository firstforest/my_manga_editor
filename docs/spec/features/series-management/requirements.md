## 概要

複数の作品 (`Manga`) を「シリーズ」でまとめて扱えるようにする機能。
連載の各話や、同じ設定を共有する読み切り群が増えてくると、
現在のカンバン (`/manga`) は全作品がフラットに並ぶため目的の作品を探しにくい。

本 spec では **シリーズを独立したエンティティにせず、作品に付ける単一のラベル (文字列)** として扱う。
シリーズは「名前」しか持たず、同じシリーズ名を持つ作品の集合がシリーズである。
利用者はカンバン上部の絞り込みでシリーズを選び、そのシリーズの作品だけを見る。

---

## ユーザーストーリー

### US-1: 作品にシリーズ名を付けたい (priority: P1)

As a 漫画家（ユーザー），
I want 作品にシリーズ名を付け／付け替え／外すことができ，
so that 連載の各話や同じ世界観の作品群を1つのまとまりとして扱いたい。

#### Acceptance Criteria

- AC-1.1: THE SYSTEM SHALL 各作品に **シリーズ名 (文字列 1つ)** を持たせ、編集画面 (`/manga/:mangaId`) の
  作品名の近くに現在のシリーズ名を表示する
- AC-1.2: WHEN ユーザーがシリーズ名の入力欄を確定した
  THE SYSTEM SHALL 入力値の前後の空白を除去した文字列をその作品のシリーズ名として保存する
- AC-1.3: WHILE 作品がどのシリーズにも属していない (シリーズ名が空文字)
  THE SYSTEM SHALL 入力欄に「シリーズ未設定」のプレースホルダを表示する
- AC-1.4: WHEN ユーザーがシリーズ名を空文字で確定した
  THE SYSTEM SHALL その作品を「未所属」に戻す（シリーズ名フィールドを空文字で保存し、
  ドキュメントからフィールドを削除しない）
- AC-1.5: WHILE ユーザーがシリーズ名を入力している
  THE SYSTEM SHALL 既存のシリーズ名のうち入力文字列を含むものを候補として提示し、
  選択すればその名前がそのまま入力される（表記ゆれによるシリーズ分裂を防ぐため）
- AC-1.6: IF シリーズ名が 100 文字を超える
  THEN THE SYSTEM SHALL 保存せず `シリーズ名は100文字以内で入力してください` の SnackBar を表示し、
  変更前のシリーズ名を保持する
- AC-1.7: WHEN シリーズ名が保存された
  THE SYSTEM SHALL 同じ利用者の他の開いている画面（カンバンの絞り込み候補を含む）へ
  Firestore の snapshot 経由でその変更を反映する

#### Edge Cases
- シリーズ名に前後の空白のみを入力 → trim の結果が空文字なので「未所属」扱い (AC-1.4)
- 既存シリーズ名と大文字小文字だけが違う文字列を入力 → **別のシリーズとして扱う**（完全一致で判定する）
- 全角／半角の違い、旧字体などの表記ゆれ → 別シリーズ扱い。AC-1.5 の候補提示で予防する
- オフライン中の変更 → Firestore キャッシュに書き込まれ、再接続時に同期される
- 作品を削除した結果、あるシリーズに属する作品が 0 件になる → そのシリーズ名は候補から自然に消える

### US-2: カンバンをシリーズで絞り込みたい (priority: P1)

As a 漫画家，
I want 作品一覧のカンバンを特定のシリーズだけに絞り込み，
so that 連載1本分の進行状況（アイデア／制作中／完成）だけを見たい。

#### Acceptance Criteria

- AC-2.1: THE SYSTEM SHALL 作品一覧 (`/manga`) のカンバンの上部に、
  `すべて` / `未所属` / 存在する各シリーズ名 を選べる絞り込み UI を表示する
- AC-2.2: THE SYSTEM SHALL 絞り込みの選択肢のうちシリーズ名の一覧を、
  利用者が持つ全作品のシリーズ名から重複を除いて文字列の昇順に並べたものとする
- AC-2.3: WHEN ユーザーが特定のシリーズを選択した
  THE SYSTEM SHALL カンバンの3列 (アイデア／制作中／完成) に、そのシリーズ名を持つ作品だけを表示する
- AC-2.4: WHEN ユーザーが `未所属` を選択した
  THE SYSTEM SHALL シリーズ名が空文字の作品だけを表示する
- AC-2.5: WHILE いずれかのシリーズで絞り込まれている
  THE SYSTEM SHALL 各列のカード枚数バッジを**絞り込み後の件数**で表示する
- AC-2.6: WHILE いずれかのシリーズで絞り込まれている, WHEN ユーザーが「新規作成」を押下した
  THE SYSTEM SHALL 選択中のシリーズ名を初期値として持つ作品を作成する
  (`すべて` / `未所属` 選択時は未所属の作品を作成する)
- AC-2.7: WHILE いずれかのシリーズで絞り込まれている
  THE SYSTEM SHALL カードのドラッグ&ドロップによるステータス変更を従来どおり許可し、
  ドロップ後もシリーズ名を変更しない
- AC-2.8: IF 絞り込み中のシリーズに属する作品が 0 件になった
  THEN THE SYSTEM SHALL 絞り込みを `すべて` に戻す（存在しないシリーズで空の画面に取り残さない）
- AC-2.9: THE SYSTEM SHALL 絞り込みの選択をアプリ起動中のみ保持し、
  再読み込み後は `すべて` から始める

#### Edge Cases
- 1つもシリーズが存在しない → 絞り込み UI は `すべて` / `未所属` のみを出す
- 全作品がシリーズ未所属 → `すべて` と `未所属` の表示内容が一致する（許容）
- シリーズ数が多い (20 件以上) → 絞り込み UI は横スクロールし、カンバンの高さを圧迫しない
- 絞り込み中に他端末で作品のシリーズ名が変わった → snapshot 反映で当該カードが列から消える／現れる

## 機能要件 (Functional Requirements)

- FR-001: THE SYSTEM SHALL シリーズを独立した Firestore ドキュメントとして持たず、
  作品ドキュメントの単一フィールドとして保持する
- FR-002: THE SYSTEM SHALL シリーズ名の同一性を **trim 後の完全一致**で判定する
- FR-003: THE SYSTEM SHALL シリーズ名の空文字を「未所属」として扱い、null と空文字を区別しない
- FR-004: THE SYSTEM SHALL シリーズ名の読み書きを `MangaRepository` に閉じ込め、
  UI から直接 Firestore を読み書きしない
- FR-005: THE SYSTEM SHALL シリーズ名フィールドを持たない既存の作品ドキュメントを
  「未所属」として読み込み、エラーにしない（後方互換）
- FR-006: WHEN シリーズ名の保存に失敗した THE SYSTEM SHALL `logger.e` にエラー詳細を残す

---

## 非機能要件 (Non-Functional Requirements)

- NFR-001: パフォーマンス: 絞り込みの切り替えは追加の Firestore 読み取りを発生させず、
  既に購読済みの作品一覧をクライアント側でフィルタして 100ms 以内に再描画する
- NFR-002: オフライン挙動: 絞り込み・シリーズ名の変更いずれも Firestore キャッシュのみで動作すること
- NFR-003: 後方互換: 本機能を含まない旧クライアントが同じデータを読んでも壊れないこと
  （シリーズ名フィールドを知らない旧クライアントはそれを無視するだけで動く）
- NFR-004: 既存データの一括移行 (バックフィル) を必要としないこと

---

## 成功基準 (Success Criteria)

- SC-001: 連載3話分の作品に同じシリーズ名を付け、カンバンでそのシリーズを選ぶと
  3作品だけが各ステータス列に並ぶ
- SC-002: シリーズ名を入力し始めると既存シリーズ名が候補に出て、選択すると完全一致の名前が入る
- SC-003: 本機能のリリース前に作られた既存の作品が、`未所属` として一覧に表示され、
  シリーズ名を後から付けられる

---

## スコープ外 (Out of Scope)

- シリーズを独立したエンティティにすること（シリーズ ID / シリーズ専用ドキュメント）
- シリーズ単位のメモ（キャラ設定・世界観などの共有メモ）
- シリーズ内の話数・並び順の管理（第1話・第2話…の明示的な順序付け）
- シリーズ名の一括リネーム（あるシリーズの全作品のシリーズ名をまとめて変更する操作）
- 1作品が複数シリーズに属すること（タグの複数付与）
- シリーズ単位の書き出し（複数作品をまとめて1ファイルに出す）
- 絞り込み状態の永続化 / URL への反映

---

## 仮定 (Assumptions)

- ドメインモデル `Manga` の構造は [docs/design/data-model.md](../../../design/data-model.md) の現行定義に従う
- 作品一覧のカンバン (`MangaSelectPage`) とステータス3列の構成は現行のまま変えない
- 認証・権限制御は既存のまま。シリーズは利用者ごとに閉じており、他利用者と共有しない
- シリーズ名は日本語（全角）を含む任意の文字列。ファイル名等には使わないため禁止文字の考慮は不要
